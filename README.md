# DISENIO_INTERFACES

Ejercicios de Diseño de Interfaces (2º DAM) con PyQt6 y Qt Designer.

## Estructura

| Carpeta | Contenido |
|---|---|
| [`EjTema1`](EjTema1) | Tema 1: widgets y layouts escritos a mano con PyQt6 (QPushButton, QLabel, layouts, QToolBar, diálogos...). Usa `cuadrado.py`, `dialogs.py`, `Img/` e `icons/` |
| [`EjTema2`](EjTema2) | Tema 2: Qt Designer (`.ui` → `pyuic6`), paletas, iconos y hojas de estilo `.qss`. Ver su [README](EjTema2/README.md) |
| [`QtDesigner`](QtDesigner) | Ejercicios de clase originales con Qt Designer |
| [`QtDesigner2`](QtDesigner2) | Qt Designer, paletas, `.qss` (selectores, pseudoestados, cambiar de estilo) y calculadora. Ver su [README](QtDesigner2/README.md) |
| [`QTDesigner_ALT`](QTDesigner_ALT) | Versión alternativa de los mismos ejercicios + plantilla y repaso. Ver su [README](QTDesigner_ALT/README.md) |

## Requisitos

```bash
pip install PyQt6 PySide6
```

Ejecuta cada ejercicio abriendo **su carpeta** en VS Code: las imágenes, iconos y `.qss`
se buscan con rutas relativas a la carpeta desde la que se ejecuta.
